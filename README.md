___
Игра: "Отара"  
Язык программирования: C++  
Графическая библиотека: SFML  
___
1. Введение  

Задачей курсовой работы является создание игры "Отара". "Отара" - это игра в жанре головоломки с элементами планирования. В ней игроку предстоит управлять компьютерным персонажем - пастухом, цель которого загнать отару, то есть стадо овец, в загон. Игра предлагает различные уровни, в зависимости от которых будет изменяться ландшафт игрового поля, количество овец, а также доступное время.
___
2. Техническое задание  

Игрок управляет персонажем игры (пастухом) с помощью клавиатуры, а именно, с помощью клавиш WASD. Задача игрока - загнать всех овец за определенное время в загон.

Для этого должны быть реализованы функции управления игровым персонажем, а также алгоритмы проверки коллизий с другими игровыми объектами.

Проверяются столкновения игрока и овец со стенами, препятствиями и границами загона. Игрок не может проходить сквозь препятствия; овцы отталкиваются от них.

Овцы убегают от игрока, притягиваются к другим овцам (стадное поведение) и отталкиваются от стен и препятствий. Поведение реализуется через векторную математику (steering behaviors), без поиска пути. Овца считается пойманной, когда её центр оказывается внутри области загона. Пойманная овца перестаёт двигаться и меняет цвет (или помечается визуально).

Уровни состоят из игрового поля, по которому перемещается игровой персонаж. Ландшафт игрового поля меняется в зависимости от уровня: могут появляться препятствия, узкие проходы, замедляющие объекты. Кроме того, на каждом уровне есть ограничение по времени. Если время, за которое игрок выполнил задачу оказалось больше допустимого времени, то уровень считается не пройденным.

Всего в игре должно быть реализовано 3 уровней, которые будут открываться игроку по мере прохождения. Когда игрок проходит один из уровней, то его лучшее время записывается в таблицу достижений. Лучшим прохождением считается наименьшее время, за которое игрок загнал всех овец в загон.

В игре должен быть реализован следующий пользовательский интерфейс:
- главное меню, включающее в себя кнопки «Играть», «Рекорды» и «Выход»;
- меню уровней, открываемое нажатием на кнопку «Играть», отображающее все уровни игры, активные в зависимости от их прохождения игроком;
- меню достижений, открываемое нажатием на кнопку «Рекорды», содержащее таблицу лучших прохождений по уровням;
- во время прохождения уровня вверху экрана отображаются: номер уровня, оставшееся время, количество пойманных овец и общее число овец на уровне;
- при успешном завершении уровня выводится экран «Уровень пройден» с временем прохождения. При истечении времени — экран «Уровень не пройден» с кнопками «Повторить» и «В меню».

Движение пастуха и овец должно быть анимировано.

На протяжении всей игры должна играть фоновая музыка, а все действия пастуха (перемещение, столкновения с предметами, попадание овцы в загон и т.д.) должны иметь звуковое сопровождение. При желании, игрок может отключить все звуки.
